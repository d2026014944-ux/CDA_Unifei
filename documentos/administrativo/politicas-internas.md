# Políticas Internas — DACDA

> **Status:** minuta de políticas internas.

## 1. Conflitos de interesse

- declarar conflitos reais, potenciais ou aparentes;
- registrar declaração em ata quando houver deliberação relacionada;
- impedir votação/decisão da pessoa diretamente interessada.

## 2. Uso de recursos

- aplicar recursos apenas em finalidades institucionais do DACDA;
- exigir registro e comprovação mínima para cada movimentação;
- vedar uso para benefício pessoal.

## 3. Armazenamento documental

- manter versões oficiais em repositório institucional;
- padronizar nomes de arquivos e histórico de revisões;
- definir controle de acesso para documentos sensíveis `[PREENCHER]`.

## 4. Proteção de dados

- coletar somente dados estritamente necessários;
- anonimizar dados antes de publicação pública;
- revisar periodicamente práticas de privacidade e segurança documental.
