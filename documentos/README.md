## 🔗 Conexão com a Infraestrutura Técnica

O DACDA governa o desenvolvimento do projeto computacional acadêmico abrigado neste mesmo repositório:

- 🐧 **[CDA OS](../initramfs/)** — Sistema operacional Linux imutável com OverlayFS e inicialização rápida
- 📡 **[Rede Mesh](../scripts/mesh/)** — Malha L2 distribuída via `batman-adv` sem dependência de internet
- 🖥️ **[CDA Center](../cda-center/)** — Painel de telemetria em tempo real direto do kernel
- 🧪 **[QEMU Mesh Lab](../tests/qemu/)** — Laboratório virtual com 4 nós para testes de resiliência e Dask
- 📄 **[Ficha do Projeto CDA OS](projetos/cda-os-cluster.md)** — Especificação formal do cluster
