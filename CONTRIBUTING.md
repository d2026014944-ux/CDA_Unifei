# Contribuindo com o DACDA

Obrigado por contribuir com a base documental do DACDA.

## Fluxo de contribuição

1. **Abra uma issue**
   - descreva contexto, objetivo e impacto esperado;
   - indique se o documento é minuta, modelo, rascunho ou versão aprovada.
2. **Crie uma branch**
   - padrão sugerido: `tipo/tema-curto` (ex.: `docs/estatuto-capitulo-orgaos`).
3. **Implemente a proposta**
   - mantenha linguagem institucional, clara e inclusiva;
   - use `[PREENCHER]` para dados não confirmados.
4. **Abra um pull request**
   - relacione a issue;
   - descreva alterações, riscos e pendências de validação.
5. **Revisão e merge**
   - revisão por pelo menos [PREENCHER] pessoas da gestão/comissão documental.

## Regras de dados pessoais e anonimização

- Não publicar CPF, RG, endereço residencial, telefone pessoal, e-mail pessoal sem autorização formal, dados bancários ou assinaturas.
- Sempre anonimizar listas de presença, relatos sensíveis e registros que permitam identificação indevida.
- Quando necessário, substituir por marcadores como `[PREENCHER]` ou `[DADO ANONIMIZADO]`.
- Em dúvida sobre proteção de dados, solicitar revisão antes do merge.

## Boas práticas de revisão

- verificar coerência entre documentos e links relativos;
- confirmar se o texto diferencia minuta/modelo de documento aprovado;
- validar se há dependências institucionais ou jurídicas marcadas com `[PREENCHER]`.
